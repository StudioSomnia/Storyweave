Choices & effects

var:courage >= 2stat condition
item:lanternhas an item
var:name is "Mira"text match
var:courage += 1add to a stat
item:lantern += 1add to inventory
var:name = "Mira"set text

Use var: for stats and item: for inventory in text, conditions, and effects. Display names appear on the stat screen; IDs are used in commands. Bare IDs such as courage still work. Use and, or, and not to combine conditions. Separate effects with a new line or ;.

Inventory categories show only items whose count is above zero. Type \[ to print a literal bracket. Images are embedded as data, so the export never needs separate image files.
